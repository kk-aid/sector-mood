# 설계: 차트판 화면 (드러켄밀러식 체계적 차트 스캔) — 섹터 무드판

작성 2026-10-29 · 클로드(Opus, 채팅) · 상태: 초안 → 구현
짝 문서: kkfund-lab `docs/design/claude/차트판_설계.md` v2 (규칙 원본) · kkfund-lab 결정 2026-10-29-10 (이원화)

## 0. 결론
- 섹터 무드에는 **화면(①시장 그룹판 + ②오늘 바뀐 것 + 월봉 상태)** 만 넣는다. 이벤트 정식 등재·펀더멘털 교차 확인·성과 기록(판정)은 kkfund-lab 전용
- 상태 규칙은 kkfund 차트판 §2.1 과 **같은 식·같은 값**(rule_version 1)을 쓴다 → 두 사이트의 ▲▼◆ 가 같은 뜻
- 새 수집기 없음. 기존 macro(yfinance·FRED)·업종 ETF(strength_etf)·종목 가격 이력에서 계산만 추가. 공개 저장소라 Actions 시간 제한 없음

## 1. 범위 (기존 자료 재사용)
| 묶음 | 출처 (기존) | 카드 수 |
|---|---|---|
| 매크로: 환율·미 국채·채권 ETF·원자재·크립토·변동성·글로벌 지수 | `pipeline/macro.py` GROUPS | ~40 |
| 업종·테마 ETF | `strength_etf.json` 의 ETF 목록 | 기존 수 |
| 업종 그룹(미·한·일 섹터) | 재구성 시총가중 섹터 지수(기존 weekly 계산) | 섹터 수 × 3 |

- 원자재 선물(=F)은 카드 이름에 '(선물 연속)' 표기 — 만기 교체 갭이 있음(kkfund GPT 반론 3)
- **크레딧 스프레드(ICE BofA, BAML*)**: FRED 가 제3자 제공을 제한하는 시리즈 → 공개 화면 제외 권고. CEO 결정 전까지 차트판 카드에는 넣지 않고, 기존 매크로 화면은 그대로 둠(§6 질문)

## 2. 상태 규칙 (kkfund 차트판 §2.1·결정 -05 그대로)
| 봉 | 기준선 | 기울기 | 완충 price / level |
|---|---|---|---|
| 일 | SMA50 | SMA_t − SMA_{t−10} | 1.0% / 5bp |
| 주 | SMA30 (확정 주) | SMA_t − SMA_{t−4} | 2.0% / 10bp |
| 월 | SMA10 (확정 월) | SMA_t − SMA_{t−3} | 3.0% / 15bp |

- ▲ 진입 = 종가 > SMA×(1+b) 그리고 기울기 > 0 · ▼ 진입 = 종가 < SMA×(1−b) 그리고 기울기 < 0 · 히스테리시스: 반대 진입 조건이 나올 때까지 유지 · 그 밖 ◆ · 이력 부족·결측 = '판정 불가'
- level(금리·변동성 포인트)은 bp·포인트 절대 완충, 순위 없음, 52주 범위 백분위 표시
- 진행 중 주·월봉은 상태 계산에 쓰지 않음(확정 봉만). 카드에는 '이번 주 잠정' 을 별도 작게 표시
- 환율 방향: 기존 매크로 표기(원/달러 등)를 그대로 쓰고 카드에 '상승 = 달러 강세' 문구

## 3. 화면
| 보기 | 내용 |
|---|---|
| 차트판 (새 vtab `board`) | 묶음별 카드 격자: 2년 주봉 종가선 + 30주선, 일·주·월 상태 칩, 1개월 %, 3개월 상대(%p, 같은 시장 기준지수 대비), 52주 고점 대비 · 정렬 = 3개월 상대 |
| 오늘 바뀐 것 (차트판 맨 위 띠) | 직전 관측일 대비 상태가 바뀐 카드, 월 > 주 > 일 순 |

- '오늘 바뀜' 은 **관측일** 기준. 데이터 최신 관측일이 기대 최신일보다 이르면 '지연' 표시
- 색: 기존 섹터 무드 색 규칙 따름

## 4. 자료
- `docs/data/board.json`: `{rule_version, generated_at, cards:[{id, group, name, kind, obs_date, state:{d,w,m}, prev_state:{d,w,m}, changed:[...], ret_1m, rel_3m, from_52w_high, pct_52w, weekly:[[date, close, sma30]...]}]}`
- 업종 그룹 카드는 시장별 파일 `docs/data/<mkt>/board.json` (같은 형식)
- 이전 상태 비교용 `prev_state` 는 직전 실행의 board.json 에서 읽음(관측일이 같으면 비교 안 함)
- 매크로 yfinance 는 지금처럼 매 실행 2년 전체 재다운로드(auto_adjust) → 조정 기준 혼합 문제 없음. 월 상태용으로 2년이면 충분(SMA10+기울기 3 = 13개월)

## 5. 단계
1. `pipeline/board.py` (상태 계산 + 단위 테스트: 경계 깜빡임 반례 `C_t=100+0.0001t+0.01(−1)^t` 에서 상태가 매일 바뀌지 않음, 확정 봉만 사용, 판정 불가)
2. run.py 에 board 단계 추가(실패해도 다른 단계 진행)
3. app.js `board` 보기 + 오늘 바뀐 것 띠
4. 텔레그램 brief 에 '주·월 상태 변경' 한 줄 (일 상태 변경 제외)

## 6. 질문 (CEO)
- Q1 기존 매크로 화면의 ICE BofA 하이일드·투자등급 스프레드를 공개 화면에서 내릴지 (권고: 내림, HYG·LQD 가격 카드가 대체)
